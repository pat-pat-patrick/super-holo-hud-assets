# Super Holo HUD Assets

The models, materials, textures and sounds of Super Holo HUD, a holographic HUD mod for Helldivers 2. Among them are the icons drawn from the game's own artwork: stratagems, ammo modes, boosters, samples and Super Credits, and the fallen teammate's skull. Because that artwork belongs to the game's rights holders, the package is published separately and free of charge.

On its own, the package changes nothing in the game. It is required by Super Holo HUD.

## Download

The package is attached to each [release](https://github.com/pat-pat-patrick/super-holo-hud-assets/releases).

## Installation

1. Install the package with a mod manager, beside Super Holo HUD, and deploy.
2. Each version of Super Holo HUD requires the Assets version it was built with; without it, Super Holo HUD stays off and the game's own HUD is shown.
3. Supported on the official game and on HellForge.

| Super Holo HUD | Super Holo HUD Assets |
|---|---|
| 1.250.0 – 1.256.2 | 2.1.0 – 2.1.2 |
| 1.257.0 – 1.259.4 | 2.2.0 |

### 下载

素材包附在每个[发布版本](https://github.com/pat-pat-patrick/super-holo-hud-assets/releases)中。

### 安装

1. 使用 MOD 管理器将素材包与 Super Holo HUD 一同安装，然后部署。
2. 每个版本的 Super Holo HUD 都需要与之配套的 Assets 版本；未安装时 Super Holo HUD 不启用，游戏原生界面正常显示。
3. 支持正式版游戏和 HellForge。
